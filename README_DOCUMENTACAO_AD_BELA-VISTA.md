## Como exportar para PDF

1. Abra cada arquivo `.md` em um editor compatível (ex.: VSCode).
2. Use **Exportar/Imprimir** do editor (ou extensão de Markdown PDF) para gerar o PDF.

> **Dica:** para preservar a formatação, use o modo impressão ou a extensão “Markdown PDF”.
