## 🎨 CONVERTENDO PARA PDF

### Opção Rápida (Recomendada)
1. Abra VS Code
2. Instale extensão "Markdown PDF"
3. Abra arquivo `.md`
4. Pressione `Ctrl+Shift+P`
5. Digite "Markdown PDF: Export (pdf)"
6. Pronto!

### Opção Profissional
1. Instale Pandoc
2. Execute script em `GUIA_CONVERSAO_PDF.md`
3. PDFs com template profissional
4. Cabeçalho e rodapé customizados

**Detalhes completos**: Veja `GUIA_CONVERSAO_PDF.md`
